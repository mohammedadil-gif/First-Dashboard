# E-Commerce Sales Dashboard (Excel)

## Project Overview
Created an interactive sales dashboard in Microsoft Excel to analyze sales performance, profit, quantity sold, and regional trends.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Timeline Filters

## Key Insights
- Analyzed sales by region and category.
- Identified top-performing products.
- Tracked monthly sales trends.
- Built interactive KPI cards and filters.
